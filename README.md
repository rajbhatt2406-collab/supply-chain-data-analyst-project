# 📦 Supply Chain Data Analyst Project

## 📌 Project Overview
This project focuses on analyzing supply chain data to identify trends, patterns, and business insights related to sales, inventory, shipping, and operational efficiency.

The project includes data cleaning, exploratory data analysis (EDA), and visualization to help understand supply chain performance and improve business decision-making.

---

# 🎯 Objectives
- Analyze supply chain operations
- Identify sales and profit trends
- Monitor inventory performance
- Detect shipment delays
- Generate business insights using data analysis
